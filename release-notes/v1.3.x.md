# v1.3.X

Version 1.3 focuses on providing tools to Content Pack Creators. While this release doesn't have a lot of bullet points, a LOT of work went into trying to make Pack creation as easy and smooth as possible!

{% hint style="info" %}
**Breaking Change**

Removed an item called "Sprinkles" that was intended to add texture to grass and other areas. Grass and other terrains now have built in texture. The Sprinkles item was generally a bad idea as it spammed a low-opacity item into the map that made selecting everything else annoying.

Maps that used the Sprinkle item may be broken. If you have a broken map, please [contact us via the Itch community forums](https://narfox.itch.io/terrascriber/community) and we should be able to fix it!
{% endhint %}

### Bugfixes

* Fixed various crash issues
* Fixed issue where item names were lost in the map file
* Improved error messaging when a map cannot be loaded
* Fixed some issues with item nudging and rotation

### Roadmap Features

* Created a new Pack Chooser screen that shows all available content packs (except for the Core pack, which cannot be edited)
* Created a new Pack Editor screen that allows users to edit Tilesets and Items
* Created Tileset editing mode that allows users to create, edit, and delete tilesets
* Created Item editing mode that allows users to create, duplicate, edit, and delete items
